# 大学・研究所 財務データの取得手順と注意点

`data/finance.json` を構成する各ソースの取得方法。自動化されているものと、年次で手動（エージェント）再抽出が必要なものがある。

## 自動（scripts/fetch_finance.py が毎回取得）

### 国立大学法人（NIAD統合Excel）
- 入口: https://www.niad.ac.jp/support/university_finance/ のアンカーテキスト「法人別概要財務諸表」を辿る（URLのID/ハッシュは年版ごとに変わるため直リンク禁止）
- 1ファイルに 92法人 × 6年度 の BS/PL。単位は千円（シートに単位表記なし）
- シートにより データ開始列が異なる（PL=D列、BS_資産=E列）。行ラベルは A〜C列連結
- 「政府計」行は国・公立大学分を含む——使わない
- 年1回（12〜3月頃）更新

### 国立研究開発法人・大学共同利用機関法人（財務諸表PDF）
- 機関の一覧・URL・単位・ラベルは **`data/institute_sources.json`（レジストリ）** に集約。fetch_finance.py はこれを読んで抽出する
- レジストリの書式: `template`（{year}=西暦年度 / {reiwa} / {reiwa2}=ゼロ埋め）または `urls`（年度→PDF配列。BS/PL分割は全部列挙）。`unit: 千円` は取得時に円へ換算。`extra` で機関固有の収益内訳ラベルを追加
- **URL不透明な機関（NEDO・QST・NIMS・KEK・NINS・NCVC・NCNPなど）は自動では新年度を拾えない**: 年1回、各開示ページから新年度のPDF URLを調べてレジストリの `urls` に手動（またはエージェント）で追記する。templateの機関は自動で新年度を試行する
- 抽出の罠（pdf_metric が対応済み）:
  - ラベルは文字間スペース入りでレンダリング → 全空白除去後に照合
  - 康熙部首の異体字（⽤⾦⼀等）を使うPDFがある（がん研C） → NFKC正規化
  - （注1）等の注記マーカーの数字を値として拾わない → `(注…)` を除去
  - 数値は厳密な3桁カンマ区切りで照合（隣列と融合した数値を正しい桁で切る）
  - 「資産合計」は行頭アンカー必須（「流動資産合計」に誤マッチする）
- 運営費交付金は損益計算書の収益化額を採用（決算報告書の交付額とは別物。混ぜない）
- **フォント破損PDF**（テキスト抽出不能）は `static_values` に vision抽出値（円）をチェックイン: JAXA 2019-20 / JAEA 2020 / NICT 2021-23 / ROIS 2019 / がん研C 2020-21 / JAMSTEC 全年度 / JST 2024 / 建築研 2019・2022 / 長寿C 2023（いずれも経常利益との整合を検証済み）
- **layoutモード必須**（既定抽出で表の列順が崩れる）: 森林機構・QST・NIMS。逆に自然科学研究機構はlayoutモードで出力が壊れるため既定のまま
- 個別の欠測: 産総研 r2（2020年度）は概要文書のみ／国環研は貸借対照表が2段組で資産のみ欠測
- 会計基準: 大学共同利用機関法人（KEK/ROIS/NINS/NIHU）は国立大学法人会計基準（千円単位・行政コスト計算書なし）、他は独立行政法人会計基準
- JAXAの経常費用>経常収益は実態（経常損失を臨時利益「運営費交付金精算収益化額」で補填し当期総利益は小さな黒字）

## 手動再抽出（年1回 → data/private_finance_fy2025.json を更新）

### 主要私立16大学（各学校法人の開示PDF）
全16校PDFのみ。**予算/決算/差異の3列構成で、実績は中央の決算列**（前年比較ではない）。

| 大学 | 罠 |
|---|---|
| 早稲田 | waseda.jp はCloudflare保護。curlは403 → 実ブラウザ or TLS偽装（curl_cffi impersonate）が必要。集計行が縦書き回転テキストで pdftotext から欠落 → ページ画像化して読む |
| 慶應 | 集計行が回転テキスト（早稲田と同じ）。束ねPDFの後半に資金収支計算書があり同名ラベルが並ぶ——事業活動収支計算書のページに限定する |
| 上智 | 完全スキャンPDF（テキスト層ゼロ）。開示ページはNuxt SPAでHTMLにリンクが出ない → ブラウザで解決。ファイル名規則も年により変わる |
| ICU | 2025年度から「Print to PDF」のスキャン結合になりテキスト層消失 → 画像読取 |
| 法政・中央 | サブセットフォントにToUnicodeが無く pdftotext が文字化け → 画像読取 |
| 関西学院 | PDF取得に Referer: https://ef.kwansei.ac.jp/disclosure/report が必須（無いと403） |
| 立命館 | file.jsp?id=数値 の不透明URL → 毎年ページ再スクレイプ |
| 日本女子 | 開示は corp.jwu.ac.jp（www側は404） |
| 東京理科 | 最も簡単: `{year}_3.pdf` で2008年まで遡れる |
| 立教 | 最も素直（年別ページ+規則的ファイル名）。ただし http への301が挟まる |

- 2025年度から改正学校法人会計基準（令和6年文科省令28号）適用 → 2024年度以前との比較は注意（立命館の教育活動収支差額の赤字は賞与引当金組替の影響）
- 科研費直接経費は預り金のため事業活動収支計算書に出ない。研究隣接は「受託事業収入」（付随事業収入内）のみ
- 抽出値は独立した二重抽出で全値一致を確認するのが慣例（2026-08 実施時は一致）
